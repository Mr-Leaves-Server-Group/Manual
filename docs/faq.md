# 常见问题

## 1.怎么样重新生成世界

- 绝大部分情况下，您只需要**删除服务器世界/存档文件夹**（通常为world或者world_nether等），然后重启服务器即可生成新世界。
- 您也可以**通过游戏内的指令**，来生成新世界，例如：饥荒可以使用游戏内的ESC菜单中的 “重置世界” 功能来生成新世界。具体操作请参考对应游戏的教程。
- 如果需要完全卸载游戏并重新安装，请前往** [重装服务器教程](/2-serveradvanced/reinstall) **查看详细教程。

## 2.文件夹/大文件传不上去
超过100M的文件，或文件夹，请使用 **[大文件传输教程](/2-serveradvanced/filetransfer)** 中的步骤操作。

## 3.服务器性能不足/经常崩溃
通常因为错误配置或者游戏本身的性能需求过高导致，您可以尝试以下方法：

1. **服务器性能升级**：按未使用时长补差价升级CPU/内存，前往**[官网下单](https://mlsg.mr-leaves.com/store/index.php?rp=/knowledgebase/2/%E5%A6%82%E4%BD%95%E5%8D%87%E7%BA%A7%E9%85%8D%E7%BD%AE.html)**。
2. **优化游戏设置**：降低游戏的模组数量或者调整游戏的性能设置。
3. **检查服务器日志**：查看服务器日志文件，找出导致崩溃的具体原因。
4. **联系技术客服**：如果以上方法无法解决问题，请联系客服寻求帮助。

## 4.服务器无法启动/启动后崩溃

1. **模组服务器**
    1. **确保模组兼容**：确保所有模组/插件版本与当前游戏版本兼容/一致。
    2. **逐个禁用模组**：通过一个个禁用模组来排查哪个模组导致服务器崩溃。
    3. **检查模组配置**：确保模组的配置文件没有错误，特别是一些需要手动配置的模组。
2. **原版服务器**
    1. **检查启动参数**：确保服务器的启动参数正确，特别是Java参数（如果是Java游戏）。
    3. **检查配置文件**：确保服务器的配置文件，有按照照教程正确配置，特别是避免有错误的参数。
    2. **检查游戏版本**：服务器可能因为太久没有更新而与当前游戏版本不兼容。尝试删除所有服务器文件，重新安装解决。
