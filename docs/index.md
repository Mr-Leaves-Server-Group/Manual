## 4.来源声明

- 本文档基于 [翼龙中国](https://github.com/pterodactyl-china/panel) 面板而撰写，同样适用于 [Pterodactyl原版](https://github.com/pterodactyl/panel) 面板，主要为经验总结  
- 游戏预设基于 [Pelican Eggs](https://github.com/pelican-eggs) 开发，并结合了我们自己的经验进行调整，适用于大多数国人玩家的习惯和需求，且部分预设可能与原版有所不同，增加了更多自动化功能，减少了玩家的操作难度。
