# 太空狼人杀（Among Us）
轻社交推理游戏，适合中小型朋友局和活动局。

---

## 1.推荐配置
- 小团体（4-10人）：2C / 2G
- 常规活动（10-15人）：2C / 4G
- 多房间/活动场景：4C / 8G

## 2.开服前准备
- 明确使用官方房间还是社区私服方案
- 规划地图、回合时长与语音沟通方式
- 制定基础管理规则（恶意退房、辱骂等）

## 3.开服流程
### 3.1 基础参数
- 房间可见性（公开/私有）
- 玩家人数上限与地图选择
- 讨论时间、投票时间与任务数量

### 3.2 平衡性设置建议
- 内鬼数量与移动速度平衡
- 任务总量和视觉任务开关
- 紧急会议次数与冷却时间

## 4.活动服建议
- 预设新手档与进阶档两套参数
- 保留比赛规则模板
- 建议由主持人统一开局节奏

## 5.运维建议
- 活动前 30 分钟压测与连通测试
- 活动期间保留管理员在线
- 活动后归档配置用于复用

## 6.常见问题
- 房间不可见：检查区域、版本与可见性
- 玩家频繁掉线：检查网络波动和地区选择
- 体验失衡：根据人数动态调整参数
