# 流放者柯南（Conan Exiles）
开放世界生存建造游戏，玩法包含探索、奴隶系统与据点战争。

---

## 1.推荐配置
- 休闲服（5-15人）：4C / 8G
- 社区服（15-35人）：6C / 12G
- 大型 PVP 服：8C / 16G+

## 2.开服前准备
- 规划模式：PVE / PVE-C / PVP
- 确认是否启用 BattlEye 与白名单
- 规划重启窗口与离线保护规则

## 3.开服流程
### 3.1 基础参数
- 服务器名称、人数上限、端口设置
- 经验倍率、采集倍率、掉落倍率
- 建造损坏时间段与冲突规则

### 3.2 首次启动检查
- 验证地图初始化是否完成
- 确认管理员权限与 RCON 可用
- 客户端连接测试与存档写入测试

## 4.Mod 管理
- 统一 Mod 列表顺序并固定版本
- 更新模组后先检查兼容性
- 发生问题优先回退最后一个改动

## 5.核心参数建议
- 新手服适当提升采集/经验
- PVP 服建议明确破坏时段
- 长线服建议降低离线惩罚强度

## 6.运维与备份
- 每日自动备份 + 每周完整备份
- 更新前手动备份存档与配置
- 保存管理员操作日志

## 7.常见问题
- 进服卡加载：检查模组列表和版本一致性
- 建筑消失：检查衰减规则与服务器清理策略
- 延迟过高：优化实体数量与重启频率
