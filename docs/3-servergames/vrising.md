# 夜族崛起（V Rising）
吸血鬼题材生存建造游戏，支持 PVE/PVP 与城堡发展玩法。

---

## 1.推荐配置
- 小规模（1-10人）：4C / 8G
- 常规社区（10-30人）：6C / 12G
- 高并发 PVP：8C / 16G+

## 2.开服前准备
- 明确模式：PVE / PVP / 全掠夺
- 设定服务器重置周期（赛季制或长期档）
- 规划是否开启跨时区友好设置

## 3.开服流程
### 3.1 基础参数
- 服务器名称、端口、最大人数
- 游戏模式、难度、城堡限制
- 管理员权限与访问控制

### 3.2 关键配置文件
- 服务器主配置文件路径
- 世界参数与规则文件路径
- 修改后重启并验证是否生效

## 4.参数调优建议
- 新手服：降低 Boss 压力，提高资源倍率
- 竞技服：提高冲突强度，限制保护机制
- 长线服：降低磨损，避免玩家流失

## 5.Mod 与工具（若使用）
- 先在测试服验证再上线
- 插件版本与服务端版本保持一致
- 记录插件依赖与回滚方案

## 6.运维建议
- 设定自动重启与自动备份
- 重大更新前做完整快照
- 发布更新公告并预留回滚窗口

## 7.常见问题
- 参数未生效：确认编辑了正确配置文件
- 玩家城堡异常：检查城堡上限与保护规则
- 更新后崩溃：先禁用新增扩展逐项排查
