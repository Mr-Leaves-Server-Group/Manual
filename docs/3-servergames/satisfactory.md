# 幸福工厂（Satisfactory）
第一人称自动化建造游戏，强调产线规划与多人协作。

---

## 1.推荐配置
- 小规模建造（2-6人）：4C / 8G
- 中型工厂（6-20人）：6C / 12G
- 超大型工厂：8C / 16G+

## 2.开服前准备
- 确认服务器名称与会话设置
- 规划访问权限（私有/公开）
- 明确自动保存与维护时段

## 3.开服流程
### 3.1 基础参数
- 服务器名、端口、最大在线人数
- Session 名称与访问控制
- 自动保存周期与备份数量

### 3.2 首次联机验证
- 测试创建新档与加入旧档
- 测试多玩家同时加入稳定性
- 确认重启后工厂进度不丢失

## 4.进阶配置建议
- 建议开启定时重启降低长期泄漏风险
- 大图建议适度限制并发人数
- 重要节点建设前手动备份

## 5.Mod 与扩展（若使用）
- 客户端与服务端 Mod 需一致
- 更新前先备份并在测试档验证
- 出错时先禁用新增 Mod 排查

## 6.运维建议
- 固定低峰重启窗口
- 每天至少 1 次自动备份
- 保留周备份用于灾难恢复

## 7.常见问题
- 无法加入会话：检查版本、密码与端口
- 卡顿严重：减少超大传送带与实体密度
- 进度丢失：确认存档路径与自动保存是否生效
