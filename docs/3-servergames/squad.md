# 战术小队（Squad）
大型战术团队射击游戏，强调沟通、分工和地图层管理。

---

## 1.推荐配置
- 低负载测试（20-40人）：6C / 12G
- 常规对战（60-80人）：8C / 16G
- 满编高质量服（80+人）：12C / 24G+

## 2.开服前准备
- 规划服务器定位（休闲 / 竞技 / 训练）
- 准备轮图与图层池（Layer Pool）
- 制定管理员排班与处罚规则

## 3.开服流程
### 3.1 基础参数
- 服务器名、端口、最大人数
- 地图轮换、队伍平衡与投票规则
- 管理员权限与日志输出

### 3.2 首次验证
- 验证服务器是否在列表可见
- 验证玩家加入、换图、重开流程
- 检查日志是否有脚本或插件报错

## 4.地图与规则管理
- 按时段准备不同强度图层
- 限制高负载图层连续出现
- 公示换图与活动规则

## 5.管理与反作弊
- 维护管理员命令白名单
- 记录封禁原因与证据
- 定期复查误封与申诉

## 6.运维建议
- 高峰期前进行连通性与性能检查
- 低峰期重启并归档日志
- 每周备份配置与轮图文件

## 7.常见问题
- 搜不到服务器：检查查询端口与地区设置
- 游戏内卡顿：优化轮图并控制高负载地图
- 管理命令无效：检查权限组与配置生效状态
