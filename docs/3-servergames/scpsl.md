# SCP 秘密实验室（SCP:SL）
多人阵营对抗游戏，偏重语音协作、回合节奏与插件管理。

---

## 1.推荐配置
- 基础对局（10-20人）：4C / 8G
- 常规社区（20-40人）：6C / 12G
- 高峰活动服：8C / 16G+

## 2.开服前准备
- 明确服务器定位（原版平衡 / 插件娱乐）
- 规划管理规则与管理员权限
- 确认是否启用插件框架（如 EXILED）

## 3.开服流程
### 3.1 基础参数
- 服务器名称、端口、人数上限
- 回合相关参数（重生、时长、投放）
- 管理员凭据与远程管理设置

### 3.2 首次验证
- 检查日志是否正常加载地图与回合
- 验证管理员命令是否可用
- 验证重启后参数持久化

## 4.插件与扩展
- 插件版本必须匹配服务端版本
- 新插件先测试服验证再上线
- 出现异常优先禁用最近新增插件

## 5.运营建议
- 设置新人友好公告与规则
- 固定维护时段与重启计划
- 记录封禁与惩罚操作

## 6.常见问题
- 玩家进服闪退：检查版本兼容与插件冲突
- 回合异常结束：检查插件逻辑与日志错误
- 指令失效：检查权限组与配置加载
