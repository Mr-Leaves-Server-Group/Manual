# 非生物因素（Abiotic Factor）
科幻合作生存游戏，强调探索、科研与基地推进。

---

## 1.推荐配置
- 小队体验（2-6人）：4C / 8G
- 常规联机（6-16人）：6C / 12G
- 长期开荒服：8C / 16G

## 2.开服前准备
- 确认服务端版本与客户端一致
- 规划存档策略（长期档 / 阶段档）
- 预设管理员规则与公告模板

## 3.开服流程
### 3.1 基础参数
- 服务器名称、人数上限、访问密码
- 难度、掉落、资源刷新参数
- 自动保存与重启窗口设置

### 3.2 首次验证
- 首连创建角色与重连测试
- 检查关键日志与报错信息
- 确认存档可读写

## 4.玩法参数建议
- 休闲合作：降低惩罚、提高资源
- 硬核挑战：提高敌对压力与资源消耗
- 新手社区：适度提高容错与恢复速度

## 5.扩展与兼容（若支持）
- 仅使用与当前版本匹配的扩展
- 每次更新后先进行联机回归测试
- 保留上一个稳定版本备份

## 6.运维建议
- 每日备份 + 每周归档
- 版本更新前广播维护通知
- 建议维护变更记录

## 7.常见问题
- 启动失败：检查参数拼写与配置格式
- 玩家掉线：检查网络与并发占用
- 存档异常：回滚到最近可用备份
