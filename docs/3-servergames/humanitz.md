# 人性末日（HumanitZ）
末日僵尸开放世界生存，偏重团队协作与基地发展。

---

## 1.推荐配置
- 小队体验（4-10人）：4C / 8G
- 中型社区（10-25人）：6C / 12G
- 高强度战斗服：8C / 16G+

## 2.开服前准备
- 确认游戏版本与服务器镜像版本一致
- 规划服务器定位：硬核生存 / 休闲合作 / PVP
- 预先制定重启时间与公告规范

## 3.开服流程
### 3.1 基础参数
- 服务器名、最大玩家、公开状态
- 初始难度、资源刷新、僵尸密度
- 管理员密码与远程管理参数

### 3.2 首次验证
- 检查日志是否正常加载地图
- 验证玩家创建角色与重连流程
- 验证重启后存档可持续读取

## 4.玩法参数建议
- 新手友好服：降低僵尸伤害、提高掉落
- 硬核服：提高感染压力、降低资源刷新
- 团队服：适度提高载具与建造效率

## 5.Mod 与扩展（若支持）
- 优先使用兼容当前版本的扩展
- 一次只新增少量扩展，逐步验证稳定性
- 出现报错先回滚最近改动

## 6.运维与备份
- 每日定时备份存档
- 重要更新前手动备份一次
- 记录版本号、参数变更与更新时间

## 7.常见问题
- 玩家无法加入：检查版本与密码
- 频繁回档：检查磁盘空间与自动保存周期
- 卡顿严重：降低实体密度并优化重启频率
